Accuracy is measured, not claimed. Three open demo systems were run under load with their telemetry recorded. Calibrated on one run, the model predicted runs it never saw: p99 within 2–10%, breaking points within 0–13%, cost within 0–3%. See accuracy.

Start

npm install
npm run dev            # the app on http://localhost:5173 — the docs are at /docs/
npm run sim -- …       # the CLI
npm run mcp            # the MCP server for AI agents
  • Using an AI agent? Give it the agent tools: it connects to your Prometheus and Jaeger, builds the model and verifies changes itself.
  • Open the Backtest tab: the three reference systems are built in. Then bring your own data.
  • Or start on Live, a system already failing, and follow the next move.
  • Looking for a specific question? Use cases. Want the full list? Everything it does.
