Episodes

  1. Scripted episodes

    A single board or two side by side, captions on a timeline, camera moves onto components, live swaps to the fixed design. Episodes are also generated from any comparison and from any audit incident.

  2. The stage

    What gets rendered, at the chosen format (Feed 4:5, Square 1:1, Story 9:16, Slide 16:9), brand and theme.

  3. Render in the browser

    Plays the episode frame by frame on a virtual clock and encodes it on the page: an MP4, a GIF, a PNG still after every caption and those stills as a PDF carousel (LinkedIn shows a PDF as a swipeable post). Nothing is uploaded; it takes about three times the clip's length.

Rendering from the command line

The same output, frame-perfect with ffmpeg, from a checkout with the dev server running. The Studio shows the exact command for the current selection under Or from the command line.

npm run dev
npm run record -- <episode-id> --aspect 4:5 --brand personal --theme terminal [--gif]
npm run record -- --card card.json        # a backtest card or clip

Output: an MP4 (H.264), a PNG still after every caption, a PDF carousel of the stills, and optionally a GIF. Rendering is deterministic (a fake clock drives every animation) and takes about real time.

Backtest results become cards too: see cards and clips.
